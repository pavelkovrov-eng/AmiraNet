# What 11 real exam sections say about how to write our content

Source: 11 English sections from four psychometric simulations, OCR'd from
scanned PDFs with answer keys taken from the real text layer. 88
sentence-completion items, 44 restatements, 99 reading questions, 21 passages.
All keys verified.

These are measurements, not impressions. Each one changed or corrected
something we were doing.

## 1. The vocabulary pool cannot be enumerated

Each section contributes about 31 new distinct words. Across all 11 sections,
339 distinct words fill 352 option slots — a 4% repeat rate. The curve is
flat, not flattening.

Fifty sections would yield roughly 1,550 words and still not saturate.

**Consequence:** a bank built to cover the pool by enumeration will always
lose. What generalises is morphological decomposition (`abduction` = `ab-` +
`duct`), confusable discrimination (`extensive` / `expensive`, `adopt` /
`adapt`), and connector logic — the last of which *is* a closed set and can be
covered completely.

## 2. The register is ordinary precision, not academic vocabulary

Verified correct answers include `stored`, `joined`, `single`, `warm`,
`loads`, `rose`, `detects`, `portrait`, `dispute`. The exam tests whether you
know common words *precisely* enough to choose among four plausible options.

Building the bank on the Academic Word List alone was wrong at the root, not
merely narrow. Measured coverage of real options at that point was 9%.

## 3. Distractors cluster on a shared morpheme in about a third of items

| pattern | share of 88 items |
|---|---|
| 3+ options share a suffix | 31% |
| 3+ options share a prefix | 3% |
| 3+ options share an initial letter | 10% |
| any clustering | **36%** |

Example sets: `obstruction / abduction / disruption / corruption`;
`proclamation / migration / narration / elevation`;
`single / severe / similar / stubborn`.

An earlier version of this note claimed clustering was the primary distractor
mechanism. Measured across the full corpus it is 36% — real and significant,
but not the rule. `confusableWith`, which records resemblance to the *correct
answer*, covers the other 64% correctly.

**Consequence:** the schema needs both. Clustering is a property of the option
*set*; `confusableWith` is a property of a single word. One field cannot carry
both.

## 4. Reading item mix — we are weighted wrong

| item type | real (99 items) | ours (20 items) |
|---|---|---|
| purpose of a paragraph | 24% | 15% |
| according to the text | 22% | 10% |
| inference | 20% | 20% |
| best title | 11% | 10% |
| word meaning in context | 8% | 15% |
| main purpose of text | 7% | — |
| main idea of paragraph | 4% | — |
| reference / antecedent | 2% | — |
| NOT / except | 2% | — |

We over-weight word-meaning-in-context, which feels like vocabulary work but is
the exam's smallest category. We under-weight paragraph purpose and plain
factual retrieval, which together are 46% of real reading questions.

Two item types we have never written at all: reference/antecedent ("'they'
in line 14 refers to —") and NOT/except.

## 5. Restatement length is an exploitable regularity — do not copy it

In the real corpus the correct restatement is longer than the distractor
average in 28 of 44 items (64%).

**We should deliberately not replicate this.** Matching it would train the user
to pick the longest option, a heuristic that fails on the other 36% and
teaches nothing about meaning. Our restatement bank should sit near 50% so the
only way through is to read.

## 6. Passage length

Real passages: median 292 words, range 191–343. Ours: 254, 258, 271 — inside
the range but consistently short of the median.

## Item type we have no model for

`criteria / stimuli / theses / alumni` — an item whose four options are all
irregular Latin or Greek plurals. Nothing in our schema or content represents
this.
